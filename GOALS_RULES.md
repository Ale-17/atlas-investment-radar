# Goal-aware monthly plan

La necesidad mensual teórica de un objetivo es:

`(objetivo - ahorrado) / meses restantes`

Atlas no asigna automáticamente toda esa necesidad. Limita la aportación según:

- cobertura del colchón;
- agresividad;
- prioridad;
- dinero libre real.

El orden conceptual es:

`ingreso -> gastos base -> dinero libre -> objetivos -> inversión/ocio/reserva`

Cuando el colchón es muy bajo, objetivos e inversión se reducen para proteger liquidez.
